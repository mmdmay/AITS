交通安全邊緣運算網頁與部署 - 實作講義

帶領你從提示詞工程、模型部署，到完成專屬的 AI 交通安全公益宣傳網站。

任務一：運用 AI 生成網站框架

請將以下提示詞（Prompt）複製到 Google Gemini 或 ChatGPT 中，並將括號內的文字修改為你的專題主題，讓 AI 幫你生成網頁骨架。

你是一位資深的前端工程師。請幫我用單一的 index.html 檔案，搭配 Tailwind CSS，寫一個【主題：偏鄉校園周邊交通安全 AI 計畫】的公益宣傳網頁。

網頁必須包含以下 5 個區塊（由上而下）：
1. 首頁橫幅 (Hero Section)：吸睛標題與行動呼籲按鈕。
2. 痛點對照表 (Why Choose Us)：比較傳統交通執法與開源 AI 的差異。
3. 核心功能矩陣 (Core Features)：卡片式設計，展示 4 種 AI 交通辨識能力。
4. 法規與應用場景 (Use Cases)：說明可以應用在哪些危險路口。
5. 8 大違規場景規格清單：用表格呈現具體的偵測項目。

程式碼請保持簡潔，配色請使用科技藍與安全綠，並預留一個 ID 為 'demo' 的區塊讓我後續放互動體驗。

取得程式碼後，請在你的電腦建立一個 index.html 檔案並貼上。

任務二：核心區塊內容客製化

網頁不能只是複製貼上！請用文字編輯器打開 index.html，找到對應區塊進行內容修改：

  • 痛點與解決方案：想想你們學校周邊的交通問題。是硬體建置太貴？還是警察無法24小時站崗？
  • 核心功能矩陣：除了未戴安全帽、未禮讓行人，你們這組還想增加什麼辨識項目？
  • 法規與情境應用：搜尋《道路交通管理處罰條例》，說明你的 AI 系統如何「輔助預防」。
  • 詳細規格清單：將違規場景寫得更具體，例如「距離3公尺內觸發警示」、「夜間光源不足的限制」。

我們要將訓練好的模型放進網頁中，實作「一鍵體驗」功能。請依序貼上以下三段程式碼：

找到網頁中的 <section id="demo"> 區塊（將 AI 幫你寫的空區塊刪除），替換成以下程式碼：

        <p class="text-slate-400 mb-10">照片不會上傳至雲端，全程在您的瀏覽器內進行 AI 邊緣運算，保護隱私。</p>
        
        <!-- 上傳按鈕區 -->
        <div id="uploadBox" class="bg-slate-800 rounded-2xl p-8 border border-slate-700 border-dashed hover:border-blue-500 transition-colors relative">
            <input type="file" id="imageInput" accept="image/*" class="absolute inset-0 w-full h-full opacity-0 cursor-pointer z-10">
            <div class="flex flex-col items-center pointer-events-none">
                <i class="fa-solid fa-cloud-arrow-up text-5xl text-blue-500 mb-4"></i>

步驟 C：邊緣運算邏輯 (JavaScript)

找到網頁最底部的 </body> 標籤正上方，貼上以下邏輯程式碼。注意：請務必修改程式碼最上方的 API Key 與專案 ID！

<!-- Roboflow AI 辨識邏輯 -->
<script>
    /* ==========================================
       👇 學生修改區塊 START 👇
    ========================================== */
    const RF_API_KEY = "rf_在這裡貼上你的API金鑰"; // 你的 Publishable API Key
    const RF_PROJECT_ID = "你的專案名稱-abcd1"; // 你的專案 ID
    const RF_VERSION = 1; // 你的模型版本號碼

    function getColorByLabel(labelName) {
        if (labelName === "No_Helmet" || labelName === "Jaywalking") {
            return "#ef4444"; // 紅色 (違規)
        } else if (labelName === "Vehicle") {
            return "#3b82f6"; // 藍色 (車輛)
        } else {
            return "#10b981"; // 綠色 (預設)
        }
    }
    /* ==========================================
       👆 學生修改區塊 END 👆
    ========================================== */

    const imageInput = document.getElementById('imageInput');
    const uploadBox = document.getElementById('uploadBox');
    const loader = document.getElementById('loader');
    const resultContainer = document.getElementById('resultContainer');
    const canvas = document.getElementById('canvas');
    const ctx = canvas.getContext('2d');
    let model; 

    roboflow.auth({ publishable_key: RF_API_KEY }).load({
        model: RF_PROJECT_ID, version: RF_VERSION
    }).then(function(m) {
        model = m; console.log("AI 模型載入完成！");
    }).catch(function(err) { console.error("模型載入失敗", err); });

    imageInput.addEventListener('change', function(e) {
        const file = e.target.files[0];
        if (!file) return;
        if (!model) { alert("AI 模型下載中，請稍候！"); return; }

        uploadBox.classList.add('hidden');
        loader.classList.remove('hidden');
        resultContainer.classList.add('hidden');

        const reader = new FileReader();
        reader.onload = function(event) {
            const img = new Image();
            img.onload = function() {
                canvas.width = img.width; canvas.height = img.height;
                ctx.drawImage(img, 0, 0);

                model.detect(img).then(function(predictions) {
                    loader.classList.add('hidden');
                    resultContainer.classList.remove('hidden');
                    const fontSize = Math.max(16, Math.floor(img.width * 0.025));
                    ctx.font = `bold ${fontSize}px sans-serif`; ctx.textBaseline = 'top';

                    predictions.forEach(function(prediction) {
                        const rx = prediction.x - (prediction.width / 2);
                        const ry = prediction.y - (prediction.height / 2);
                        const rw = prediction.width; const rh = prediction.height;
                        const labelName = prediction.class;
                        const confidence = Math.round(prediction.confidence * 100);
                        const labelText = `${labelName} (${confidence}%)`;
                        const boxColor = getColorByLabel(labelName);

                        ctx.lineWidth = Math.max(3, Math.floor(img.width * 0.005));
                        ctx.strokeStyle = boxColor; ctx.strokeRect(rx, ry, rw, rh);
                        const textWidth = ctx.measureText(labelText).width;
                        const padding = fontSize * 0.4;
                        ctx.fillStyle = boxColor;
                        ctx.fillRect(rx, ry - fontSize - (padding * 2), textWidth + (padding * 2), fontSize + (padding * 2));
                        ctx.fillStyle = '#ffffff';
                        ctx.fillText(labelText, rx + padding, ry - fontSize - padding);
                    });
                    if (predictions.length === 0) alert("未偵測到訓練目標！");
                });
            };
            img.src = event.target.result;
        };
        reader.readAsDataURL(file);
    });

    function resetDemo() {
        resultContainer.classList.add('hidden');
        uploadBox.classList.remove('hidden');
        imageInput.value = ''; 
    }
</script>

任務四：發布上線 (GitHub Pages)

  1. 建立 Repository：登入 GitHub，點擊右上角「+」選「New repository」。命名為 traffic-ai-demo 並設為 Public，點擊 Create。
  2. 上傳網頁：點擊「uploading an existing file」，將你的 index.html 拖曳上傳，並點擊 Commit changes。
  3. 啟用 Pages 服務：進入 Repository 的 Settings (設定)，左側選單點擊 Pages。
  4. 選擇來源：在 Branch 下拉選單中，將 None 改選為 main（或 master），點擊 Save。
  5. 取得網址：等待約 1~2 分鐘後重新整理，頁面上方會顯示你的專屬網址！

任務五：網頁版 VS Code 客製化

網站上線後，不需要每次都在電腦改檔重新上傳。利用 GitHub 隱藏密技，隨時隨地修改網頁：

魔法快捷鍵：

在你的 GitHub 專案檔案列表畫面，確定輸入法為英文，按下鍵盤的 . (句號鍵)。

  1. 畫面會瞬間切換成深色的 VS Code 編輯器。
  2. 左側點開 index.html，你可以在此修改文字內容、標題或更換顏色。
  3. 修改完成後，點擊左側邊欄第三個圖示「原始檔控制 (Source Control)」。
  4. 在 Message 框內簡短寫下修改紀錄（如：更新組別名稱）。
  5. 點擊 Commit & Push。約一分鐘後，重新整理你的專屬網址，網頁就會更新囉！
